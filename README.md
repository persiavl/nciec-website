# NCIEC Services — nouveau site (front-end)

Static site generated by a zero-dependency Node script (Node ≥ 18).

```bash
npm start          # build + preview on http://localhost:4173
npm run build      # → dist/  (deploy this folder)
```

- `src/pages/*.mjs` — one file per page (texts from the copy deck v1.0, FR)
- `src/layout.mjs` — header, mega menu, footer, shared components
- `src/data.mjs` — company details, solution list, quote-form options
- `public/assets/` — CSS, JS, fonts (self-hosted), optimised images & teaser video
- `dist/_redirects` and `dist/.htaccess` — 301 map from the copy deck annex

**Client placeholders** `[…]` are rendered highlighted in yellow. The **Mode relecture** button (bottom left) also shows the editorial notes and decision points. Remove the button before go-live.

**Forms** validate and show a confirmation, but nothing is sent yet. Wire them up in `public/assets/js/main.js` → `showSuccess()`.

Every CTA links to `/contact/?prestation=<key>&objet=<topic>#devis`, which prefills the quote form.

Palette with contrast ratios: `/charte/` (noindex).
